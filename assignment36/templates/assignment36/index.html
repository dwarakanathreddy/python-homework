Assignment 36: Simple RPG Character

Create an RPG battle system using Character classes.

Assignment Instructions

  • __init__: set all attributes, max_health = health
  • attack(other): calculate damage = max(0, self.attack_power - other.defense + random(-2,2))
  • is_alive: return True if health > 0
  • heal: restore min(amount, max_health - health), return amount healed
  • get_status: return dict of all stats
