Assignment 35: Library Book Tracker

Track library books using Book and Library classes.

Assignment Instructions

  • Book.__init__: set title, author, isbn, is_available=True
  • Book.check_out: set is_available=False if available, else raise error message
  • Book.return_book: set is_available=True
  • Book.get_info: return dict of book details
  • Library.__init__: set self.books = []
  • Library.add_book: append Book to self.books
  • Library.find_book: search by title, return Book or None
  • Library.get_available_books: return list of available books
