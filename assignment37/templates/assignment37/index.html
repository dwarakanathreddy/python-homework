Assignment 37: Vehicle Fleet Manager

Manage a vehicle fleet using inheritance and method overriding.

Assignment Instructions

  • Vehicle.__init__: set make, model, year, fuel_type
  • Vehicle.get_info: return dict of basic info
  • Vehicle.calculate_fuel_cost: assume 10L per 100km, return cost
  • Car.__init__: use super() and add num_doors
  • Car.get_info: call super().get_info() and add num_doors
  • Truck.__init__: use super() and add payload_capacity
  • Truck.calculate_fuel_cost: call super() result and multiply by 1.3
